## What Was Delivered

### M6.6 — Dependencies Capability

**Question answered:** What does this project depend on?

**Files added:**
```text
internal/output/dependencies.go
internal/output/dependencies_test.go
```

**Registered in:**
```text
internal/cli/capabilities.go
```

**Verification:**
```text
aayam dependencies .          ✓ terminal output correct
aayam dependencies --json .   ✓ JSON envelope correct, capability field = "dependencies"
```

**Design decisions:**
- Consumes `snap.Codebase.Dependencies` directly — no new discovery
- Groups `Dependency.From → []To` at render time, not at model time
- Test packages (`capability_test`, `cli_test`, etc.) appear correctly because the dependency model itself captures them — the renderer makes no judgment
- Empty dependency list renders a clean `(no internal dependencies detected)` message rather than crashing

aayam git --json .   ✓ JSON envelope correct, capability field = "git"
                     ✓ working_tree_state = "dirty" (correct — uncommitted M6.6-M6.8 work)
                     ✓ head.state = "branch", head.branch = "main"
                     ✓ health block present with objective signals
```

**Design decisions:**
- Consumes `snap.Git` directly — no new Git commands
- Non-repository path renders cleanly rather than omitting the section
- `formatWorkingTreeState` and `formatGitDate` are private helpers inside `git.go` — not exported, not shared with history
- `formatGitDate` is reused by `history.go` via the same package — no duplication

aayam history --json .   ✓ JSON envelope correct, capability field = "history"
                         ✓ No branch, working_tree_state, or head fields present
                         ✓ commit_count = 42, latest commit correct
```

**Design decisions:**
- Intentionally omits `Branch`, `Working Tree`, `HEAD` — those belong to `git`
- JSON shape is deliberately narrower than `git` JSON — only historical data
- `jsonHistoryCommitPtr` returns `nil` for empty repositories rather than a zero-value struct
