## JSON Contract

All three capabilities follow the capability-scoped JSON pattern established by M6.2.

```json
{ "capability": "project",       "project":       { ... } }
{ "capability": "structure",     "structure":     { ... } }
{ "capability": "relationships", "relationships": { ... } }
```

No capability returns fields belonging to another capability.

---

## Architectural Rule Preserved

No capability re-runs discovery. All three consume the existing `ProjectSnapshot` passed through `capability.Context`.

```text
aayam project .
aayam structure .
aayam relationships .
        │
        ▼
  single Discover() call
        │
        ▼
  ProjectSnapshot
        │
  ┌─────┼──────┐
  ▼     ▼      ▼
project structure relationships
renderer renderer  renderer
```

The graph used by M6.5 is the S5 graph already present on `snap.Graph`. It is not rebuilt.
